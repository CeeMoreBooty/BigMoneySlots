#   Minimum size: 320 px on the short side
#   Maximum size: 3840 px on the long side

#   Recommended: 1080 × 1920 px (portrait)
#
# ── 7-inch tablet (optional but recommended) ──────────────────────────────────
#   Same size rules as phone
#   Recommended: 1200 × 1920 px
#
# ── 10-inch tablet (optional) ────────────────────────────────────────────────
#   Recommended: 1600 × 2560 px
#
# ── Feature Graphic (required for store listing) ──────────────────────────────
#   Exact size: 1024 × 500 px
#   Format: PNG or JPEG
#   No alpha / transparency
#
# ── How to take screenshots ───────────────────────────────────────────────────
